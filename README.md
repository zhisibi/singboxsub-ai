# ⚡ SingBox Sub Converter & Local HTTP Server
> **Sing-Box 1.14+ & Mihomo / Clash Meta 局域网订阅转换与服务器**  
> 一款基于 Kotlin & Jetpack Compose 打造的高性能 Android 本地订阅转换与局域网 HTTP 分发服务器应用。

---

## 🌟 核心功能特性

### 1. 🚀 多协议订阅转换引擎
- **Sing-Box 1.14+ 原生支持**：生成标准且符合最新规范的 `Sing-Box JSON` 配置，完美适配移动端与桌面端 Sing-Box 客户端。全面支持标准的 `sing-box://import-remote-profile?url=...` 快捷 scheme 导入格式与 QR 二维码。
- **Mihomo / Clash Meta YAML**：导出兼容 Clash Meta 及 Mihomo 内核的标准 `YAML` 配置文件。
- **Base64 通用节点订阅**：支持导出包含 `vless://`, `vmess://`, `ss://`, `trojan://`, `hysteria2://`, `socks://`, `http://` 等协议的通用 Base64 订阅文本。
- **混合订阅与 Scheme 链接一键导入**：支持解析远程 HTTP/HTTPS 订阅链接、`sing-box://`、`clash://` 等客户端快捷 scheme 链接、剪贴板多协议 URI 以及复杂 JSON/YAML 格式文本。

### 2. 🌐 高性能局域网 HTTP 服务器
- **零配置开箱即用**：内置轻量级并发 HTTP 服务，支持同一局域网下的手机、电视、电脑或路由器直接拉取订阅配置。
- **智能 IP 绑定与多网卡自适应**：自动监测与切换 Wi-Fi/局域网 IP，提供本机环回 (`127.0.0.1`) 与局域网 (`192.168.x.x`) 双地址模式。
- **动态安全鉴权 Token**：可自定义全站访问密钥 (`&token=xxx`)，防止局域网内未经授权的非法请求。
- **实时访问日志与统计**：精准记录客户端 IP、访问路径、User-Agent 标识与 HTTP 响应状态码。

### 3. 🎯 专属自定义订阅分流与生成
- **自由组合与精细筛选**：在独立面板中自由勾选任意组合的节点，选定输出目标格式（Sing-Box / Mihomo / Base64）。
- **永久保存与随时编辑**：支持给自定义订阅命名、绑定独立 Token、查看节点数量并随时重新勾选调整。
- **快速链接分发**：支持一键生成局域网链接、本机链接以及二维码扫描订阅。

### 4. ⚡ 节点管理与极速 TCP 测速
- **一键批量并发测速**：基于 Coroutines 协程并发测试节点的真实网络延迟与可用性。
- **多维度节点智能排序**：
  - ⚡ **延迟优先 (极速)**：自动将低延迟可用节点置顶。
  - 🔤 **名称排序 (A-Z)**：按节点名称字母顺序排序。
  - 🧩 **协议类型分类**：按 VLESS / VMess / SS / Trojan 等协议类型归类。
  - 📌 **启用状态优先**：优先展示已勾选启用的节点。
- **多协议节点解析**：全面兼容 VLESS、VMess、Shadowsocks、Trojan、Hysteria2、Socks5、HTTP 等协议参数解析。

### 5. 🎨 现代化 UI 与沉浸式美化
- **Material Design 3 毛玻璃卡片设计**：统一各页面顶部 Hero 卡片的完整透明度与边缘对齐（`16dp` 统一上边距），配以柔和边框与 `0.85` 不透明度的半透明磨砂质感卡片，适应各种自定义壁纸。
- **高兼容性 ZXing 二维码矩阵生成**：集成标准 ZXing QRCode 编码器，支持字符集 UTF-8 与边界边距微调，生成高清、易扫描的二维码展示弹窗。
- **中英双语无缝切换**：全局中文/英文双语 UI 一键切换。
- **动态壁纸与透明度自定义**：支持内置高颜值壁纸、本地相册壁纸自定义，并可自由微调高斯模糊与暗化透明度。
- **内置 Web 仪表盘**：通过浏览器直接访问服务器根目录即可查看可视化的网页控制台。

## 🛠️ 技术栈 (Tech Stack)

- **语言**: Kotlin 1.9+
- **UI 框架**: Jetpack Compose (Material Design 3)
- **异步处理**: Kotlin Coroutines & Flow
- **本地持久化**: Room Database (KSP) + Jetpack DataStore / SharedPreferences
- **网络服务**: Java `ServerSocket` + `OkHttp3`
- **二维码生成**: ZXing Core

## 🚀 快速上手 (Quick Start)

### 1. 启动服务
打开发布的 APK 应用，在 **主页 (Dashboard)** 中确认局域网服务已启动（默认端口 `8080`）。

### 2. 导入节点
进入 **节点 (Nodes)** 选项卡，点击右上角 **+** 号：
- 可以直接贴入单条或多条节点链接（`vless://`, `vmess://` 等）。
- 也可以在 **订阅 (Subscriptions)** 选项卡导入远程订阅 URL，系统将自动解析提取其中的所有节点。

### 3. 获取或自定义订阅
进入 **订阅 (Subscriptions)** 选项卡：
- **默认订阅**：直接复制 Sing-Box (`http://<LAN_IP>:8080/sub?type=singbox`) 或 Mihomo 的局域网/本机订阅地址粘贴到对应的客户端中。
- **自定义订阅**：点击 **“🎯 生成专属自定义订阅”**，勾选部分节点与目标格式并保存，即可生成专属于该组合的固定订阅链接。

## 📦 发布与 Releases 自动化 (Publishing Releases)

本项目内置了 GitHub Actions 自动化发布工作流 (`.github/workflows/release.yml`)，支持以下两种方式自动生成并发布 Release：

1. **推送 Tag 自动发布**：
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   工作流会自动打包 Release APK (`SingBoxSub-v1.0.0.apk`) 与 AAB，并在 GitHub 仓库的 **Releases** 页面自动创建发布版本及 Release Notes。

2. **GitHub 网页手动一键发布**：
   - 进入 GitHub 仓库页面的 **Actions** 标签页。
   - 在左侧选择 **Build & Publish Release** 工作流。
   - 点击 **Run workflow** 按钮，输入版本号 Tag（如 `v1.0.0`）和发布标题，点击运行即可一键生成 Release 发布！
